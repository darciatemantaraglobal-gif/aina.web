Saya sedang membangun AINA, sebuah AI Assistant untuk mahasiswa Indonesia di Mesir (Masisir). Saya ingin menambahkan sistem productivity yang benar-benar berguna untuk kehidupan mahasiswa, bukan sekadar to-do list biasa.

Saya ingin Anda membantu saya merancang dan mengimplementasikan fitur productivity AINA dengan 3 fitur utama berikut:

1. Daily Focus + AI Automatic Recommendation
2. Admin & Dokumen Tracker
3. Smart Reminder System + Email via Resend

Fitur ini harus dibuat dengan pendekatan:
- sederhana
- usable
- mobile-friendly
- relevan untuk mahasiswa Indonesia di Mesir
- tidak over-engineered
- scalable untuk dikembangkan nanti

Stack utama saya menggunakan web app + Supabase. Saya juga sudah punya API Resend untuk email.

==================================================

==================================================

AINA bukan aplikasi produktivitas umum.

bukan seperti:

==================================================
FITUR 1 — DAILY FOCUS + AI AUTOMATIC RECOMMENDATION
==================================================

Saya ingin ada fitur Daily Focus untuk membantu user fokus pada 1–3 hal terpenting hari ini.

Tetapi saya tidak ingin ini hanya jadi to-do list manual.
Saya ingin ada bantuan AI yang bisa:
- merapikan input user
- memilih prioritas
- menyederhanakan target
- memecah target besar menjadi langkah kecil
- memberi saran fokus harian yang realistis

------------------------------------------
A. User experience yang saya inginkan
------------------------------------------

Saat user membuka fitur productivity, tampilkan section “Daily Focus Today”.

User bisa memilih salah satu dari 3 mode:

1. Manual
User menulis fokus hariannya sendiri

2. AI Assist
User menulis kalimat bebas, misalnya:
“Hari ini gue mau belajar, urus iqomah, sama lanjut revisi tugas”
Lalu AI mengubahnya menjadi 1–3 fokus yang rapi, realistis, dan terurut

3. AI Suggest
AINA membuat rekomendasi fokus harian secara otomatis berdasarkan:
- task yang belum selesai sebelumnya
- item admin/dokumen yang urgent
- due date yang dekat
- histori fokus user
- jumlah beban yang realistis

------------------------------------------
B. Rules Daily Focus
------------------------------------------

- User maksimal punya 3 fokus aktif per hari
- Fokus terkait ke tanggal tertentu
- Status fokus:
  - pending
  - in_progress
  - done
- Fokus yang selesai tetap disimpan sebagai histori
- Jika user sudah punya fokus hari ini, tampilkan progresnya
- AI harus menghindari memberi terlalu banyak tugas
- AI harus mengutamakan tugas yang paling berdampak dan realistis
- AI harus bisa memecah tugas besar jadi versi yang lebih ringan

Contoh:
Input user:
“Hari ini gue mau belajar ushul fiqh, urus iqomah, sama lanjut website”
Output AI yang diharapkan:
1. Baca 2 halaman ushul fiqh dan catat 3 poin inti
2. Siapkan berkas iqomah yang belum lengkap
3. Lanjutkan 1 bagian kecil dari website yang paling penting

------------------------------------------
C. Database yang dibutuhkan untuk Daily Focus
------------------------------------------

Tolong buat tabel misalnya:
daily_focus_items

Field minimal:
- id UUID primary key
- user_id UUID references auth.users(id)
- focus_date date not null
- original_input text nullable
- title text not null
- description text nullable
- source_type text check in ('manual','ai_assist','ai_suggest')
- status text check in ('pending','in_progress','done')
- priority integer nullable
- created_at timestamptz
- updated_at timestamptz

Tambahkan index yang relevan:
- by user_id + focus_date
- by status
- by created_at

------------------------------------------
D. Logic AI Daily Focus
------------------------------------------

Saya ingin helper / service function untuk AI recommendation.
Buat struktur yang clean agar nanti mudah disambungkan ke model AI AINA.

Minimal ada function untuk:
- menerima input bebas user
- mengubahnya menjadi 1–3 focus items
- membaca tracker admin yang urgent
- menghasilkan rekomendasi fokus harian

Tolong pisahkan:
- function untuk build prompt AI
- function untuk parse response AI
- function untuk save hasil ke database

Saya ingin AI recommendation punya aturan berikut:
- maksimal 3 fokus
- prioritaskan 1 tugas utama + 1 tugas administratif jika ada + 1 tugas ringan jika masih realistis
- jangan menghasilkan wording terlalu formal
- gunakan bahasa yang singkat, jelas, dan actionable
- jangan membuat fokus yang terlalu besar atau abstrak

FITUR 3 — SMART REMINDER SYSTEM
==================================================

Saya ingin sistem reminder yang kontekstual.

Reminder harus berdasarkan:
- daily focus yang belum selesai
- admin tracker item yang belum selesai
- due date yang sudah dekat
- progress user sebelumnya

Saya tidak mau reminder spam.
Saya ingin reminder yang cerdas dan terkendali.

------------------------------------------
A. Jenis reminder
------------------------------------------

Saya ingin minimal 3 use case:

1. Daily Focus Reminder
Jika user punya focus hari ini dan belum selesai sampai sore / malam

2. Important Admin Reminder
Jika user punya item admin/dokumen yang due date-nya dekat atau urgent dan belum selesai

3. Weekly Recap Email
Setiap minggu, user menerima ringkasan progress:
- focus yang selesai
- focus yang belum selesai
- item admin yang masih pending
- saran singkat minggu depan

------------------------------------------
B. Channel reminder
------------------------------------------

Untuk tahap awal:
- in-app reminder summary
- email via Resend

Kalau push notification belum siap, tidak masalah.
Fokus dulu ke email dan reminder panel di app.

------------------------------------------
C. Aturan anti-spam
------------------------------------------

- Jangan kirim reminder berulang untuk item yang sama di hari yang sama
- Jangan kirim daily reminder kalau semua focus hari itu sudah selesai
- Jangan kirim admin reminder kalau item sudah completed
- Weekly recap hanya 1 kali per minggu per user
- Simpan log reminder yang sudah terkirim

------------------------------------------
D. Database reminder log
------------------------------------------

Tolong buat tabel misalnya:
reminder_logs

Field minimal:
- id UUID primary key
- user_id UUID references auth.users(id)
- target_type text check in ('daily_focus','admin_tracker','weekly_recap')
- target_id UUID nullable
- channel text check in ('in_app','email')
- sent_at timestamptz not null default now()
- reminder_date date not null
- metadata jsonb nullable

Tambahkan unique protection atau logic agar tidak duplikat kirim di hari yang sama untuk target yang sama jika memungkinkan.
