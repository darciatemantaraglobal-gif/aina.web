- apa itu iqomah
- arti istiqamah

Use Perplexity as an external retrieval layer, not as the final answer engine.
AINA should still compose the final answer using its own:
- style layer
- intent detection
- answer structure
- trust layer

Meaning:
Perplexity provides supporting web-grounded source data,
but AINA remains the assistant that produces the final response.
