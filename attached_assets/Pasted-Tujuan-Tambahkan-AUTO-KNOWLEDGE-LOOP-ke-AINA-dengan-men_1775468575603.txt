Tujuan: Tambahkan AUTO-KNOWLEDGE LOOP ke AINA dengan menyimpan draft artikel ke database dan menyediakan pipeline otomatis dari gap → draft → storage.

PENTING:
- Semua perubahan HARUS additive-only
- Tidak mengubah /api/chat
- Tidak mengubah retrieval existing
- Tidak publish otomatis ke knowledge_base (default = draft)
- Aman dari infinite loop / spam

====================================================

STEP 1 — BUAT TABLE: kb_drafts

Supabase SQL:

CREATE TABLE IF NOT EXISTS kb_drafts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  topic TEXT,
  title TEXT,
  content TEXT,
  tags TEXT[],
  source TEXT DEFAULT 'auto-generated',
  status TEXT DEFAULT 'draft', -- draft | approved | rejected
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_kb_drafts_status ON kb_drafts(status);
CREATE INDEX idx_kb_drafts_topic ON kb_drafts(topic);

====================================================

STEP 2 — BUAT SERVICE: draftStorageService.js

Lokasi:
server/services/draftStorageService.js

Function:

1. saveDraft(draft)
- input: { topic, title, content, suggested_tags }
- simpan ke kb_drafts
- return saved draft

2. getDrafts(status = 'draft')
- ambil list draft

3. updateDraftStatus(id, status)
- status: approved | rejected

====================================================

STEP 3 — AUTO PIPELINE

Tambahkan function baru di knowledgeGapService:

autoGenerateDrafts()

Logic:
- ambil top topics dari getRecommendedTopics()
- filter:
  - priority = high
- limit: max 3 topic per run (biar gak spam)

Untuk setiap topic:
- generateDraft(topic)
- saveDraft()

RETURN:
{
  generated: number,
  topics: [...]
}

====================================================

STEP 4 — API ROUTES TAMBAHAN

Di knowledgeInsights.js:

Tambahkan endpoint:

1. POST /api/internal/knowledge/auto-draft
→ jalankan autoGenerateDrafts()

2. GET /api/internal/knowledge/drafts
→ ambil semua draft

3. PATCH /api/internal/knowledge/drafts/:id
body: { status }
→ update status (approved/rejected)

====================================================

STEP 5 — SECURITY

Semua endpoint:
- wajib x-internal-key === process.env.INTERNAL_API_KEY
- return 403 jika tidak valid

====================================================

STEP 6 — NON-BREAKING CHECK

Pastikan:
- /api/chat tidak berubah
- retrieval tetap pakai knowledge_base lama
- kb_drafts tidak ikut retrieval
- error di pipeline tidak crash server

====================================================
